A Home Assistant integration that provides solar production forecasts from MQTT data generated by solaredge2mqtt.

The integration subscribes to a configurable MQTT topic and exposes the forecast to Home Assistant's Energy Dashboard using the Solar Forecast API.

## Features

* MQTT-based solar forecast provider
* Compatible with Home Assistant Energy Dashboard
* Uses forecast data generated by [SolarEdge2MQTT](https://github.com/DerOetzi/solaredge2mqtt])
* Local operation without cloud dependencies
* Configurable MQTT topic

## Requirements

* Home Assistant
* MQTT integration configured and connected
* Forecast data published by solaredge2mqtt

## Installation

### HACS

1. Open HACS.
2. Navigate to **Integrations**.
3. Click the three-dot menu and select **Custom repositories**.
4. Add:

```text
https://github.com/DerOetzi/solaredge2mqtt_forecast
```

5. Select **Integration** as the category.
6. Install the integration.
7. Restart Home Assistant.

### Manual

1. Download the latest release.
2. Copy the `custom_components/solaredge2mqtt_forecast` folder into your Home Assistant `custom_components` directory.
3. Restart Home Assistant.

## Configuration

1. Open **Settings → Devices & Services**.
2. Click **Add Integration**.
3. Search for **SolarEdge2MQTT Forecast**.
4. Enter the MQTT topic used for forecast messages.

Default topic:

```text
solaredge2mqtt/forecast
```

## MQTT Payload Format

Example payload:

```json
{
  "energy_period": {
    "2026-06-05T08:00:00+02:00": 234,
    "2026-06-05T09:00:00+02:00": 654
  },
  "power_period": {
    "2026-06-05T08:00:00+02:00": 150,
    "2026-06-05T09:00:00+02:00": 700
  }
}
```

### energy_period

Hourly energy forecast values in Wh.

### power_period

Hourly power forecast values in W.

## Energy Dashboard

After configuration, the forecast is automatically available to Home Assistant's Energy Dashboard as a solar forecast provider.
