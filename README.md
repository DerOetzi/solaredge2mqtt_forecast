# solaredge2mqtt_forecast# SolarEdge2MQTT Forecast

Provides a Home Assistant solar forecast provider based on MQTT data generated by solaredge2mqtt.

## Installation

### HACS

Add this repository as a custom repository:

https://github.com/DerOetzi/solaredge2mqtt_forecast

Category: Integration

### MQTT Payload

```json
{
  "energy_period": {
    "2026-06-05T08:00:00+02:00": 234,
    "2026-06-05T09:00:00+02:00": 654
  }
}
